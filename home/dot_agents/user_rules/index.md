# User rules

The Operator writes these rules by hand. Each rule has its own file.

- `always/` holds the rules that apply in every repo and every agent.
- `scoped/` holds the rules that apply only in some environments. The entry of each rule
  gives its scope.

## Always

- `always/test-email-addresses.md` — never ask for a new mailbox for a test; plus-address
  the Operator's own address.
