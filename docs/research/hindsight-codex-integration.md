# What does the Hindsight Codex integration install, how does it hold credentials and banks, how does it interact with the codex config modifier, and can it share memory with Claude Code?

Ticket: myprysm/dotfiles#123

Versions and sources: The upstream source is the Hindsight clone at commit `f7dd3f4fd7420f7beec60c32c965e5e5cf7be066` (both sides). In this document, `codex/` means `hindsight-integrations/codex/` and `coding-agents/` means `hindsight-integrations/coding-agents/`. The Codex source is the openai/codex checkout at tag `rust-v0.160.0` (paths under `codex-rs/`). The installed Claude plugin is version 0.7.2. `R:` means this repo. No side ran an installer. No side read `~/.hindsight/`.

## Answer

The old integration (`codex/`, version 0.3.1) is deprecated. Upstream replaces it with `@vectorize-io/hindsight-coding-agents` (version 0.8.0 in the clone). One install of that package covers Claude Code, Codex and other agents. All agents share one bank per repository by default.

The old integration installs three command hooks and nothing else: `SessionStart`, `UserPromptSubmit` and `Stop`. Its installer `get-codex` downloads Python scripts from upstream `main`. The installer does not pin a version. It overwrites the whole `~/.codex/hooks.json` file. On this machine that file holds the Orca hooks, so the old installer would delete them. The replacement installer merges into `hooks.json` and also adds an MCP server and a skill.

Credentials go in `~/.hindsight/codex.json` (old) or `~/.hindsight/coding-agent.json` (new), or in the `HINDSIGHT_API_TOKEN` env variable. Both clients send a bearer token.

The #84 modifier owns only the inline `hooks.PreToolUse`. Hindsight registers no `PreToolUse` hook, so the two do not collide. But no installer writes the `hooks.state` trust hashes for Hindsight hooks. Codex skips untrusted hooks until an operator reviews them.

Sharing with Claude Code needs the same API host, token and effective bank ID. The old plugins use different default banks. The replacement package shares a bank by default. Nobody tested sharing against the deployed server.
